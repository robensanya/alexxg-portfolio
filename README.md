реальные внутренние ссылки, имена сотрудников и бизнес-цифры заменены на
вымышленные, интерфейсы внутренних систем — на заглушки с пометкой «по NDA».
Сама вёрстка, логика и анимации сохранены без изменений.

## Локальный просмотр

Просто откройте `index.html` в браузере — никакого сервера не требуется.
Для корректной работы демо с относительными путями рекомендуется поднять
локальный сервер (не обязательно, но удобнее):

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## Публикация на GitHub Pages

### 1. Создайте новый репозиторий на GitHub

Зайдите на [github.com/new](https://github.com/new), создайте пустой репозиторий
(без README, .gitignore и лицензии — они уже есть локально или не нужны).

### 2. Инициализируйте git и запушьте код

Выполните в папке проекта (замените `YOUR_USERNAME` и `YOUR_REPO` на свои):

```bash
git init
git add .
git commit -m "Initial commit: portfolio site"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### 3. Включите GitHub Pages

1. Откройте репозиторий на GitHub → вкладка **Settings**
2. В меню слева выберите **Pages**
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**
4. Branch: **main**, папка: **/ (root)**
5. Нажмите **Save**

Через 1–2 минуты сайт будет доступен по адресу:

```
https://YOUR_USERNAME.github.io/YOUR_REPO/
```

### 4. Обновление сайта после правок

```bash
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages пересоберёт сайт автоматически в течение минуты.
