🚀
Опубликовать сайт на Netlify
Самый быстрый способ — бесплатно, без кода, за 5 минут
🔴 Критично Бесплатно 5 минут
⏱ 5 мин ▼
  1. Переименуйте файл nasledie-mvp.html в index.html — это важно, браузер открывает файл с таким именем по умолчанию
  2. Зайдите на сайт app.netlify.com/drop — регистрация не нужна
  3. Перетащите файл index.html в большую область на странице
  4. Netlify автоматически создаст сайт и выдаст ссылку вида random-name-123.netlify.app
  5. Нажмите «Claim site» и зарегистрируйтесь (email + пароль) — это нужно, чтобы потом обновлять сайт
  6. В разделе «Site settings → Site name» переименуйте в nasledie-app — получится ссылка nasledie-app.netlify.app
Готово! Ваш сайт уже в интернете. Эту ссылку можно отправлять людям и указывать в заявках на гранты.

Купить домен nasledie.ru
Красивый домен добавляет доверие инвесторам и грантодателям
🟡 Важно ~700 ₽/год 30 минут
⏱ 30 мин ▼
  1. Проверьте доступность домена на reg.ru — введите nasledie.ru в поиск. Если занято — попробуйте nasledie.online (~200 ₽) или moe-nasledie.ru
  2. Зарегистрируйтесь на reg.ru, купите домен (обычно 700–900 ₽/год для .ru)
  3. В Netlify зайдите в Site settings → Domain management → Add custom domain
  4. Введите ваш домен, Netlify покажет два DNS-сервера — скопируйте их
  5. В личном кабинете reg.ru найдите раздел «DNS-серверы» для вашего домена и вставьте серверы от Netlify
  6. Подождите 1–24 часа — домен заработает автоматически
  7. В Netlify нажмите «Verify DNS configuration» → «Enable HTTPS» — SSL-сертификат установится бесплатно
Альтернативы доменных регистраторов: nic.ru, domains.ru, 2domains.ru — везде примерно одинаковые цены и процесс.

Узнайте, кто посещает сайт — это важно для грантовых отчётов
🟡 Важно Бесплатно 15 минут
⏱ 15 мин ▼
  1. Зайдите на metrika.yandex.ru и войдите через Яндекс-аккаунт

1
🔒
Написать политику конфиденциальности
Обязательна по 152-ФЗ. Без неё нельзя собирать email и имена
🔴 Критично Бесплатно 1–2 часа
⏱ 2 часа ▼
Важно: Политика конфиденциальности — это юридический документ. Для полноценного бизнеса лучше заказать у юриста (3 000–5 000 ₽). Для MVP можно использовать генератор.
  1. Зайдите на privacypolicygenerator.info или app-privacy-policy.com — бесплатные генераторы
  2. Заполните форму: название компании/проекта «Наследие», email для контактов, адрес сайта
  3. Укажите какие данные собираете: имя, email, загружаемые медиафайлы
  4. Скачайте готовый текст и переведите на русский (через ChatGPT или DeepL)
  5. Добавьте в HTML-файл отдельную страницу или ссылку внизу сайта
  6. Разместите ссылку «Политика конфиденциальности» в футере сайта

Документ должен содержать: какие данные собираете, для чего, как долго храните, кому передаёте (никому), как пользователь может удалить данные.

📋
Зарегистрировать ИП или самозанятость
Нужно для официальных грантов и работы с партнёрами
🟡 Важно для грантов Бесплатно 1–3 дня
⏱ 1–3 дня ▼

Большинство российских грантов требуют юридическое лицо или ИП. Самый быстрый вариант — самозанятость.

  1. Самозанятость (если доход до 2.4 млн ₽/год): Скачайте приложение «Мой налог» → «Зарегистрироваться» → через Госуслуги → готово за 10 минут
  2. ИП (если нужно нанимать людей или доход больше): Зайдите на nalog.ru → «Государственная регистрация» → заполните форму → подайте через Госуслуги. Пошлина — 0 ₽ при подаче онлайн
  3. Откройте расчётный счёт в банке — Тинькофф, Сбер или Точка предлагают бесплатные счета для ИП
Фонд Бортника и Сколково принимают заявки только от ИП или ООО. Росмолодёжь и ПФКИ — могут принимать физлиц, но ИП надёжнее.

🟢 Фаза 3 — Технический функционал
Превратить прототип в работающий сервис
⏱️ Неделя 2–3
1
🗄️
Подключить базу данных Supabase
Чтобы данные пользователей сохранялись при закрытии браузера
🔴 Критично Бесплатно 2–4 часа
⏱ 2–4 часа ▼

Supabase — это бесплатная база данных с готовой авторизацией. Не нужен сервер.

  1. Зарегистрируйтесь на supabase.com → «New project» → дайте имя «nasledie»
  2. В разделе «Project Settings → API» скопируйте Project URL и anon public key
  3. Добавьте в <head> вашего HTML:
    <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
  4. Инициализируйте Supabase в начале вашего JavaScript:
    const supabase = window.supabase.createClient('ВАШ_URL', 'ВАШ_КЛЮЧ')
  5. В разделе «Authentication → Providers» включите «Email» — теперь регистрация работает по-настоящему
  6. Замените функцию doLogin() на вызов supabase.auth.signInWithPassword() — за помощью обратитесь ко мне
Бесплатный план Supabase: 500 МБ БД, 1 ГБ хранилища файлов, 50 000 пользователей — этого хватит на старт.
2
🎙️
Включить реальную запись аудио/видео
Сейчас запись имитируется. Нужно подключить настоящий микрофон
🔴 Критично Бесплатно 2–3 часа
⏱ 2–3 часа ▼

Браузер умеет записывать аудио через MediaRecorder API — без плагинов. Замените функции startRecord() и stopRecord() на этот код:

Реальная запись аудио (заменить в script)
let mediaRecorder, audioChunks = [], audioBlob; async function startRecord() { try { const stream = await navigator.mediaDevices.getUserMedia({ audio: true }); mediaRecorder = new MediaRecorder(stream); audioChunks = []; mediaRecorder.ondataavailable = e => audioChunks.push(e.data); mediaRecorder.onstop = () => { audioBlob = new Blob(audioChunks, { type: 'audio/webm' }); // Здесь можно сохранить audioBlob в Supabase Storage }; mediaRecorder.start(); state.isRecording = true; // ... обновление UI (таймер, кнопка и т.д.) } catch(e) { toast('Нет доступа к микрофону. Разрешите доступ в браузере.', 'error'); } } function stopRecord() { if (mediaRecorder && mediaRecorder.state !== 'inactive') { mediaRecorder.stop(); mediaRecorder.stream.getTracks().forEach(t => t.stop()); } state.isRecording = false; // ... обновление UI }
Важно: Браузер запросит разрешение на микрофон. Сайт должен работать по HTTPS — на Netlify это включено автоматически.

🤖
Подключить реальный ИИ (Claude API)
Чтобы вопросы генерировались персонально для каждого пользователя
🟡 Важно ~$5/мес 3–4 часа
⏱ 3–4 часа ▼
  1. Зайдите на console.anthropic.com → API Keys → Create Key
  2. Скопируйте ключ. Никогда не вставляйте его напрямую в HTML — его увидят все посетители
  3. Создайте на Netlify «Edge Function» (бесплатно) — это серверный код, который скрывает ключ. Зайдите в документацию Netlify → Functions
  4. В функции делайте запрос к API Claude с промптом: «Ты — интервьюер, задающий вопросы о жизни человека. Вот его предыдущий ответ: [ответ]. Задай следующий логичный вопрос.»
  5. Из HTML вызывайте вашу Netlify Function, а не API напрямую
Стоимость Claude API — около $0.003 за 1000 слов. При 100 пользователях в месяц это примерно $2–5/мес.

Запустить в тематических сообществах
Группы ВКонтакте и Telegram с целевой аудиторией
🟡 Важно Бесплатно 2–3 часа

  1. Напишите короткий пост (3–4 предложения + ссылка) о проекте. Акцент: «помогите нам протестировать» — люди охотнее отвечают на просьбу о помощи, чем на рекламу
  2. Опубликуйте в ВКонтакте: «Генеалогия», «Семейная история», «Клуб пенсионеров», «Воспоминания СССР»

  4. Напишите в локальные библиотеки, дома культуры, клубы пенсионеров — предложите бесплатную презентацию
  5. Попросите 10–20 друзей и родственников зарегистрироваться и записать первое интервью
Цель: 30–50 зарегистрированных пользователей и 5–10 письменных отзывов. Этого уже достаточно для грантовой заявки.

Снять демо-видео проекта (2–3 минуты)
Видео — самый убедительный материал для инвесторов и грантодателей
🟡 Важно Бесплатно 1 день
⏱ 1 день ▼

  2. Структура видео: 30 сек — проблема («мы теряем истории близких»), 60 сек — решение (демонстрация), 30 сек — призыв к действию

Куда подаваться и как составить заявку

🏛️
Подать заявку в Фонд Бортника (FASIE)
До 4 млн ₽ для технологических стартапов. Один из лучших вариантов
